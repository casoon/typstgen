<div slot="cli">

```sh
cargo install typstgen
typstgen --version
```

</div>
<div slot="git">

Installs the current state of the `master` branch instead of the last release:

```sh
cargo install --git https://github.com/casoon/typstgen
```

</div>
<div slot="library">

The default features build the CLI: `cli`, `download` (fetch `@preview` packages) and `mcp` (the
[MCP server](../../guides/ai-agents/), which brings `tokio` and `rmcp`). Turn them off when you only
need the library, and add back what you use, for example `png` for page previews:

```sh
cargo add typstgen --no-default-features
cargo add typstgen --no-default-features --features download,png
```

</div>
</Tabs>

## Requirements

| | Minimum | Notes |
| --- | --- | --- |
| Rust | `1.92` | `rust-version` in `Cargo.toml`, edition 2021 |
| Typst | – | Embedded: compiled with `typst` and `typst-pdf` 0.15 |

No `typst` binary and no system fonts are needed. Typst's fallback fonts are compiled into every
build, see [Fonts](../../guides/fonts/).

## Features

| Feature | Default | Adds |
| --- | --- | --- |
| `cli` | yes | The `typstgen` binary (via `clap`) |
| `wasm` | no | A `wasm-bindgen` export for JavaScript hosts |

The Wasm build is covered in the [Rust and Wasm reference](../../reference/library/#wasm).
