<div slot="cli">

```sh
cargo install typstgen
typstgen --version
```

</div>
<div slot="git">

Installs the current state of the `master` branch instead of the last release:

```sh
cargo install --git https://github.com/casoon/typstgen
```

</div>
<div slot="library">

The default features build the full CLI: `cli`, `download`, `mcp` (which brings `tokio` and
`rmcp`), `zugferd` and `archive`, see [Features](#features). Turn them off when you only need the
library, and add back what you use, for example `png` for page previews:

```sh
cargo add typstgen --no-default-features
cargo add typstgen --no-default-features --features download,png
```

</div>
<div slot="mcp">

The CLI includes the MCP server. Register it with your AI client, for example Claude Code:

```sh
cargo install typstgen
claude mcp add typstgen -- typstgen mcp --root .
```

Its tools and other clients are covered in [AI agents](../../guides/ai-agents/).

</div>

## Requirements

| | Minimum | Notes |
| --- | --- | --- |
| Rust | `1.92` | `rust-version` in `Cargo.toml`, edition 2021 |
| Typst | – | Embedded: compiled with `typst` and `typst-pdf` 0.15 |

No `typst` binary and no system fonts are needed. Typst's fallback fonts are compiled into every
build, see [Fonts](../../guides/fonts/).

## Features

| Feature | Default | Adds |
| --- | --- | --- |
| `cli` | yes | The `typstgen` binary (via `clap`) |
| `download` | yes | Downloads missing `@preview` packages from Typst Universe (native only) |
| `mcp` | yes | `typstgen mcp`, the [MCP server](../../guides/ai-agents/); enables `cli` and `png` |
| `zugferd` | yes | ZUGFeRD / Factur-X invoice data, see [E-invoices](../../guides/e-invoices/) |
| `archive` | yes | Build manifests and `typstgen verify`, see [Archiving](../../guides/archiving/) (native only) |
| `png` | no | Page previews as PNG (`render_png`) |
| `wasm` | no | A `wasm-bindgen` export for JavaScript hosts |

The Wasm build is covered in the [Rust and Wasm reference](../../reference/library/#wasm).
