Title page, outlines, formulas, citations and appendix come from a package. The paper itself is
just text.

The `@local/thesis` template lives in typstgen's examples. It sets title page, abstract, table of
contents, lists of figures and tables, roman and arabic page numbers, numbered equations,
bibliography, appendix and declaration of authorship, in German or English.

Citations use `@key` from a BibTeX or Hayagriva file; Typst ships the styles, such as APA, IEEE,
Chicago or ISO 690. Figures such as flow diagrams come in as SVG, for example from Chartlet.

<Callout type="caution" title="Declaration of authorship">
  The bundled text is a suggestion. Universities usually prescribe their own wording; the
  `declaration` parameter takes it.
</Callout>

## Build it offline and reproducibly

Compile the paper as PDF/A-2b without fetching anything from the network.

**1. Configuration.** The template is a package inside the project; downloads and system fonts are
off.

```toml
# typstgen.toml
template_paths = ["templates"]
package_path = "packages"      # enthält local/thesis/0.1.0
download_packages = false      # nichts nachladen
use_system_fonts = false
```

**2. Compile.** Fix the standard and the timestamp: two runs give byte-identical files.

```text
$ typstgen compile thesis.typ --config typstgen.toml \
    --pdf-standard a-2b --creation-timestamp 1759276800
thesis.pdf
```

**3. When a package is missing.** With `download_packages = false` the build stops instead of
fetching:

```text
error: typst compilation failed:
paper.typ:1:9: error: package not found (searched for @preview/oxifmt:0.2.1)
```

The result is seven pages with outlines, a Chartlet figure, a formula, a table and five real
sources in APA style; veraPDF reports PDF/A-2b compliant.
